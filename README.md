# 每日英文精读 · Daily English Reading

> 每天一篇约 2000 词的**公有领域经典文本**（演讲 / 小说片段 / 散文），配**关键词积累**与**全文翻译**。地道、时效弱、无版权风险。

🌐 **在线阅读（网页版）**：https://kinghihido.github.io/english-daily/
仓库与网页双端同步发布，网页自动读取 `articles/` 下的最新文章，无需手动更新。

这个仓库由自动化任务每日维护：挑选一篇有料、有读头的英文文章，整理出生词表（含音标、词性、释义与例句），并给出完整中文翻译，帮助在英语环境中"输入 + 积累"同步进行。

## 栏目结构

每篇文章是一个 Markdown 文件，放在 `articles/` 目录下，命名格式为 `YYYY-MM-DD-<slug>.md`，包含三部分：

1. **英文原文** —— 约 2000 词，选自公有领域经典演讲 / 小说 / 散文（地道、无版权风险）。
2. **📚 关键词积累** —— 表格形式，含音标、词性、中文释义与例句。
3. **🌏 全文翻译** —— 完整中文译文（原创）。

## 📒 单词本（按字母归档）

生词不在文章里"一次性消费"，而是长期沉淀到 `vocab/` 目录：按首字母分文件（`vocab/A.md` … `vocab/Z.md`），每文件是该字母下的生词总表（单词 / 音标 / 词性 / 释义 / 例句 / 出处）。重复词不重复收录，日积月累就是一本专属词典。网页顶部点「📒 单词本」即可按 A–Z 浏览。

## 阅读建议

- 第一遍：**不通词典**通读英文，猜大意。
- 第二遍：对照**关键词积累**表，回扣生词。
- 第三遍：读**全文翻译**校验理解，把仍不熟的词抄进自己的单词本。

Happy reading. 📖
